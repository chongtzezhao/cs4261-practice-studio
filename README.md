# CS4261 Practice Studio

A standalone browser-based question bank for CS4261/5461 Weeks 1-3 and Assignments 1-3. Its 50 questions are partitioned into five mutually exclusive practice sets of 10; every set contains five MCQs, three short answers, and two long-form questions.

It includes MCQs, short-answer questions, and long-form proofs; saves responses locally; and exports a self-contained Markdown submission containing the relevant context, questions, responses, reference answers, and grading rubrics.

No account, server, API key, or build step is required.

## Use locally

Open `index.html` in a modern browser.

## Privacy

Responses remain in the browser's `localStorage` unless the user explicitly exports a Markdown or JSON file.
